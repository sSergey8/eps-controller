# EPS Controller

Контроллер на Arduino Nano для работы с электроусилителем руля **Nissan Qashqai**. Преобразует импульсный сигнал датчика скорости автомобиля в CAN-сообщения для штатного блока ЭУР.

В проекте используются Arduino Nano на ATmega328P и CAN-модуль MCP2515 с кварцем 8 МГц. Предусмотрены настройка параметров и калибровка скорости через сервисный режим.
