# Скетч EPS Controller

Прошивка для Arduino Nano, предназначенная для работы с электроусилителем руля Nissan Qashqai. Преобразует импульсный сигнал датчика скорости автомобиля в CAN-сообщения для штатного блока ЭУР.

Код скетча создан при помощи искусственного интеллекта (AI).

Контроллер позволяет передавать электроусилителю информацию о скорости автомобиля без штатного источника этих сообщений. Управление электромотором и регулирование усиления выполняет сам блок ЭУР.

## Принцип работы

Arduino измеряет время между импульсами датчика скорости с помощью аппаратного захвата Timer1. По измеренному периоду и настраиваемому коэффициенту рассчитывается скорость автомобиля.

Для сглаживания показаний используется фильтр: он отбрасывает слишком короткие интервалы между импульсами и сравнивает несколько последних измерений. Из них выбирается значение с небольшим смещением в сторону меньшей скорости, чтобы уменьшить влияние помех и резких скачков показаний. Количество измерений для фильтрации настраивается.

Рассчитанная скорость передаётся через CAN-контроллер MCP2515 в сообщении с идентификатором `0x355`. Сообщение содержит данные скорости и постоянный признак включения ЭУР `0x40`. Передача выполняется периодически и не зависит от поступления каждого отдельного импульса датчика.

```text
Датчик скорости → Arduino Nano → MCP2515 → CAN-шина → Блок ЭУР Nissan Qashqai
```

## Особенности

- **Аппаратное измерение периода.** Моменты поступления импульсов фиксируются Timer1, а обработка выполняется в основном цикле программы.
- **Фильтрация сигнала.** Используются отбрасывание слишком коротких периодов и обработка окна последних измерений. Размер окна настраивается.
- **Нижняя отсечка скорости.** При скорости ниже или равной заданному порогу в CAN передаётся нулевое значение. По умолчанию порог составляет 20 км/ч.
- **Контроль пропадания сигнала.** Если импульсы перестают поступать, передаваемая скорость обнуляется. Отправка CAN-сообщений с признаком включения ЭУР продолжается.
- **Настраиваемый коэффициент скорости.** Нужен для согласования устройства с датчиком скорости конкретного автомобиля: при одной и той же скорости частота импульсов может различаться в зависимости от датчика и его привода. Коэффициент задаёт соответствие между измеренным периодом импульсов и скоростью в км/ч. Встроенная калибровка позволяет уточнить его по известной эталонной скорости без изменения скетча. Описания данной процедуры описано в ветке по работе с сервисным режимом.
- **Сохранение параметров.** Все параметры настройки лежат в EEPROM и сохраняются после отключения питания.

## Аппаратная конфигурация

| Параметр | Конфигурация |
|---|---|
| Микроконтроллер | Arduino Nano на ATmega328P |
| Вход сигнала скорости | `D8 / ICP1` |
| CAN-контроллер | MCP2515 с кварцем 8 МГц |
| Интерфейс связи с MCP2515 | SPI, выбор микросхемы — `D10` |
| Скорость CAN-шины | 500 кбит/с |
| Исходный файл | `OCR1A_ICP1_8.ino` |

Для сборки требуется библиотека MCP2515, предоставляющая заголовочный файл `mcp2515.h`.

## Настройка и диагностика

Предусмотрен сервисный режим через последовательный порт на скорости 9600 бод. Он позволяет просматривать рассчитанную скорость, выполнять калибровку и изменять параметры обработки сигнала. Подробное описание команд будет приведено в отдельном README.
